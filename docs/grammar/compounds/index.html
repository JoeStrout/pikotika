Coining new words

Pikotika gains vocabulary by collapsing common phrases. If there is no word for a thing, describe it — and if you find yourself using the description often, close up the spaces and you have a word.

electric toilet → electric-toilet

vorto panyu

the same thing, now one word

vortopanyu

Spoken, the difference is the stress: VOR-to PAN-yu becomes vor-to-PAN-yu. One word, one stress, next-to-last syllable.

The two rules

RuleExample
Drop any te when you collapse. yoro te pomo → yoropomo
If a root ends in -ts, -ns or -ks and the next starts with a consonant, insert an e. tets kurva → tetsekurva

Head-final, left-branching

The last root is what the word is; everything before it narrows. mekaakurante is big-water-edge — an edge, of the big water: a seashore. Larger compounds usually grow out of smaller ones, which is why they group this way: mekaaku ‘ocean’ came first, and rante was appended to it.

Collapsing fixes a meaning

A compound is one word, so it can settle on one reading while the spaced phrase keeps the plain literal one.

SpacedSolid
non konten not happynonkonten sad
non mas not morenonmas less
kase peste a household animalkasepeste a cat

Length is a generality gradient

Shorter is more general, longer more specific. These are a series, not competing candidates:

PikotikaLiterallyMeaning
pomofruitany fruit
yoropomoyellow-fruita yellow fruit, usually a banana
ronkayoropomolong-yellow-fruita banana, unmistakably

A compound does not have to be fully guessable. Choosing between two readings you would have considered anyway costs one exposure, and after that the word is yours.

Check first

Someone has probably already coined it. Search Vocabulary before inventing — if a compound is in general use, that is the one to reach for.
