Coining new words

Pikotika gains vocabulary by collapsing common phrases. If there is no word for a thing, describe it — and if you find yourself using the description often, close up the spaces to mak a new word.

electric toilet

vorto toreta

the same thing, now one word

vortotoreta

Spoken, the difference is the stress: VOR-to to-RE-ta becomes vor-to-to-RE-ta. It's one word, so it gets only one stress, always on the next-to-last syllable.

The two rules

RuleExample
Drop any te when you collapse. sam pari te vema → samparivema
If a root ends in -ts, -ns or -ks and the next starts with a consonant, insert an e. mets yan → metseyan
Note tha the first rule above means that the usual grouping rules for modifiers may not apply within a compound. That's OK; words become compounds because they are common, and it's easy enough to remember the proper interpretation.

Collapsing fixes a meaning

For the same reason, a compound can settle on one meaning while the spaced phrase keeps the plain literal one, which may be more general or open to interpretation.

SpacedSolid
non konten — not happynonkonten — sad
non mas — not morenonmas — less
kase peste — a household animalkasepeste — a cat

Length is a generality gradient

Shorter is more general, longer more specific. These are a series, not competing candidates:

PikotikaLiterallyMeaning
pomofruitany fruit
yoropomoyellow-fruita yellow fruit, usually a banana
ronkayoropomolong-yellow-fruita banana, unmistakably

When possible, check first

If you have an idea for a new compound word, there's a good chance that someone has already coined it, or something equivalent. Search Vocabulary before inventing; it's better to use an existing word than create a new one.

That said, if you are speaking and need a word in the moment, go ahead and make one up! As long as your listener can understand what you mean, there is no problem.
